Token Tracker：Windows 本地 AI 编程用量与花费追踪器

Token Tracker 免费开源，支持 29 种 AI 编程工具，在系统托盘和简体中文仪表板中展示用量、预估花费与趋势。

安装

下载 Windows 安装包或便携版，也可运行 npx tokentracker-cli 配置本地采集。

仪表板默认位于本机 http://localhost:7680，无需注册账号。

主要功能

  • 用量分析：输入、输出、缓存读取和缓存写入 Token。
  • 花费分析：按模型、项目和时间段展示预估花费。
  • 活动热力图、会话记录与趋势图。
  • 查询 10 个 Provider 的使用额度。
  • IP、DNS 和 WebRTC 网络诊断。

支持的 AI 编程工具（29）

Claude Code、Codex CLI、Cursor、Gemini CLI、Antigravity、Kiro、Every Code、GitHub Copilot、Kimi Code、CodeBuddy、WorkBuddy、Grok Build、oh-my-pi、pi、Dots、Prime Agent、Craft Agents、Reasonix、Kilo CLI、Kilo Code、Roo Code、Goose、Droid、Mimo Code、ZCode、AnythingLLM Desktop、Claude Science、DeepSeek Harness、TRAE Work CN。

常见问题

如何安装 Token Tracker？

从 GitHub Releases 下载 Windows 安装包或便携版。也可以在终端运行 npx tokentracker-cli，检测已安装的 AI 编程工具并配置本地用量采集。

Token Tracker 支持哪些 AI 编程工具？

支持 29 种 AI 编程工具：Claude Code、Codex CLI、Cursor、Gemini CLI、Antigravity、Kiro、Every Code、GitHub Copilot、Kimi Code、CodeBuddy、WorkBuddy、Grok Build、oh-my-pi、pi、Dots、Prime Agent、Craft Agents、Reasonix、Kilo CLI、Kilo Code、Roo Code、Goose、Droid、Mimo Code、ZCode、AnythingLLM Desktop、Claude Science、DeepSeek Harness、TRAE Work CN。

Token Tracker 是否免费开源？

是。Token Tracker 使用 MIT 许可证，可在 GitHub 获取源代码和 Windows 安装包。

Token Tracker 会收集 Prompt 或对话正文吗？

不会。只保存 Token 数量、模型名称、时间戳和项目归属等用量元数据，不保存或上传 Prompt、回复和对话正文。

Token Tracker 统计哪些数据？

按模型、项目和时间段统计输入、输出、缓存读取及缓存写入 Token，并显示 Claude、Codex、Cursor、Gemini、Antigravity、ZCode 等 10 个 Provider 的使用额度。

如何查看不同工具的 Token 用量和花费？

在本地仪表板统一查看 29 种工具的用量、趋势和预估花费，并按模型、项目和时间段分析数据。

Token Tracker 可以离线使用吗？

本地日志解析、聚合和仪表板无需账号或云同步。查询 Provider 的实时额度和网络诊断信息时需要联网。
